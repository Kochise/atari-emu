(actually, 2-in-1 isn't a compression program, but a user-interface for other such programs. You need to get hold of the various .TTP programs for those formats in order to use it, which is not included with 2-in-1).

AUTOsort File resorter When you put a program in the AUTO folder it runs in the same order as it was placed there (i.e. the last program placed there runs last). Some programs need to run before certain other programs, and some programs cause problems with other programs if they're not run in a specific order. AUTOsort will let you resort the order of these programs as you wish. Shareware
  • Download AUTOsort
Arrowfix Fixes the window scrolling bug This little program goes in the AUTO folder and removes a bug where a single mouse-click is sometimes intepreted as two clicks, forcing the window to scroll down two lines instead of one. Freeware
  • Download Arrowfix 1.5
FoldrXXX Increase the OS pool buffer size Fixes part of the "40 folder bug" by increasing the OS pool buffer size.
Rename the program for the desired extra folders (i.e. "FOLDR100.PRG" for 100 extra folders, or "FOLDR200.PRG" for 200 extra folders) and put it in the AUTO folder.		 Freeware
  • Download Folder XXX
GEMram TOS relocator TOS contains a few bugs which can't be fixed with simple patches. GEMram goes in the AUTO folder and reads the contents of the TOS chips, then places a copy of it in RAM. Once its there, other programs can modify it to fix things or even enhance TOS with new features. Freeware
  • Download GEMram 1.6
Shbuf Increases the NEWDESK.INF buffer from 4 Kbytes up to 32 Kbytes. The NEWDESK.INF file can only contain information not exceeding 4 Kbytes. With Shbuf you can make up to 32 Kbytes available for storing information to this file (rename the file for the desired size such as "SHBUF12.PRG" for 12 Kbytes.
"SHBUF.PRG" with no number defaults to a buffer size of 16 Kbytes).

Needs GEMram.

 Freeware
